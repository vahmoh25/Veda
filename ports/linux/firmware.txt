# The firmware the driver VM's Linux loads, which the guest's initial RAM
# file system carries (/lib/firmware). Each file by the name the kernel
# asks for, where it comes from (a source below, and the file's path in
# it), and its SHA-256: from a release of linux-firmware, whose WHENCE says
# whose each file is and that anyone may redistribute it, or of
# wireless-regdb. `cargo xtask linux` fetches them (into
# target/linux/firmware); image builds check and pack them.
#
# A device of Linux's whose firmware is not here does not work in the
# driver VM: its driver (veda.config) and its firmware go in together.

source linux-firmware https://git.kernel.org/pub/scm/linux/kernel/git/firmware/linux-firmware.git/plain/{}?h=20260916
source wireless-regdb https://git.kernel.org/pub/scm/linux/kernel/git/wens/wireless-regdb.git/plain/{}?h=master-2026-09-03
