Welcome to Vindows
==================

Vindows is a modern x86-64 operating system written from scratch in Rust
(with a little C++). It runs on a small microkernel; everything else —
drivers, the file system, the window compositor and this desktop — runs as
isolated user-space programs that talk to each other over IPC channels.

Getting around
--------------

  * Start menu ........ click the logo on the taskbar or tap the Super key.
                        Start typing to search for an application.
  * Taskbar ........... click an app to open it, click again to minimise it.
                        Middle-click opens another window of the same app.
  * Calendar .......... click the clock.
  * Show the desktop .. click the thin strip at the right end of the taskbar.
  * Desktop icons ..... double-click to open; right-click the desktop for
                        more options, such as changing the wallpaper.

Keyboard shortcuts
------------------

  Super ............... open or close the start menu
  Alt+Tab ............. switch between windows
  Alt+F4 .............. close the active window
  Ctrl+C / X / V ...... copy, cut and paste text
  Ctrl+Z / Ctrl+Y ..... undo and redo in the text editor
  Ctrl+S .............. save in the text editor

Applications
------------

  Text Editor ......... this program; edits plain text files
  Files ............... browse /home/user and the read-only /system image
  Photos .............. view the pictures in ~/Pictures
  Music ............... play the songs in ~/Music
  Terminal ............ a command shell for the curious
  Task Manager ........ running programs, CPU and memory use
  Settings ............ wallpaper, display and system information
  Velocity ............ a 3D racing game
  Starfall ............ a 3D space shooter

Your files
----------

Your home folder is /home/user, with Documents, Pictures, Music and Desktop
folders. Everything you save there is kept on the home disk, so it is still
there after you restart Vindows.

Have fun exploring!
