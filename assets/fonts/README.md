| `Lato-Regular.ttf`, `Lato-Bold.ttf` | Lato | Copyright (c) 2010-2015 by tyPoland Lukasz Dziedzic, with Reserved Font Name "Lato" | SIL OFL 1.1 |
| `JetBrainsMono-Regular.ttf`, `JetBrainsMono-Bold.ttf` | JetBrains Mono (monospace) | Copyright 2020 The JetBrains Mono Project Authors | SIL OFL 1.1 |

The authoritative copyright and license strings are embedded in each font's
`name` table (records 0, 13 and 14); the system's "About" dialog displays
them at run time.
